## 2. 当前已完成能力

- 横向大屏科技风排行榜，自适应 1920×1080、1366×768 和常见超宽横屏；
- 显示姓名、名次、订单数、竞速进度、总订单数和当前领先者；
- 大屏每秒读取一次最新排名；
- 独立录入页面支持单个新增姓名、粘贴多行姓名、选择人员后录入订单号；
- 同一订单号整场只能计算一次，并发重复提交也只有一次成功；
- 数据使用 Cloudflare D1 持久保存；
- 大屏和录入页面已经完全分开，大屏没有录入控制台按钮、链接或提示。

## 3. 本地运行

环境要求：Node.js `>= 22.13.0`。

```bash
cd order-race-h5
npm ci
npm run dev
```

然后访问：

- `http://localhost:3000/`
- `http://localhost:3000/control`

提交前检查：

```bash
npm run lint
npm run build
```

如果提示 `D1 binding DB 不可用`，先核对 `.openai/hosting.json` 中的 D1 binding 是否为 `DB`，并确认当前运行方式能够注入 Cloudflare D1。

## 5. 数据规则与注意事项

- `participants.normalized_name` 唯一：同名人员不会重复创建；
- `orders.order_no_normalized` 唯一：订单号去除首尾空格并转成大写后，全场只能保存一次；
- 排名由 `orders` 实时聚合，不维护额外分数字段；
- 同分时，当前演示默认先达到该订单数的人在前；
- 大屏最多显示前 10 名；
- 空数据库首次访问时会自动建立表，并写入 8 名演示人员及演示订单。正式活动若不需要演示数据，应先调整 `db/order-race.ts` 中的 `seedDemoData` 策略，再创建正式数据库；
- 录入页目前没有单独的业务登录、撤销订单或改绑能力，不能直接作为公开生产入口。
