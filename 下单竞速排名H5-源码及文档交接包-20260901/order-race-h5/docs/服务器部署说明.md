# 量子膜下单竞速排名 H5 — 大陆服务器部署说明

适用对象：公司运维  
代码来源：GitHub 仓库当前 `main`（HTTPS + 域名部署，不依赖本说明之外的未推送补丁）  
目标：在大陆机房用 **HTTPS + 域名** 对外提供服务

---

## 1. 先读：这不是普通 Node 网站

本项目是 **Vinext + Cloudflare Workers 运行时 + D1（SQLite）**。

- 不能按 Spring / Nginx 静态站 / `pm2 start app.js` 的方式直接跑。
- **不需要 Cloudflare 账号**，也不要往 Cloudflare 再发一次。
- 大陆服务器上用 **Wrangler 本地模式（Miniflare）** 跑 Worker，数据落在本机 SQLite。
- 前面用 **Nginx 做 HTTPS 反代**。

本机数据与现有 Cloudflare / 香港反代 **不互通**。部署后是一份新库，积分从空开始（首次访问会自动建表）。

构建后打开 `dist/server/wrangler.json`，确认存在 D1 绑定，且 **binding 名称必须是** `DB`：

```json
{
  "d1_databases": [
    {
      "binding": "DB",
      "database_name": "site-creator-d1",
      "database_id": "00000000-0000-4000-8000-000000000000"
    }
  ]
}
```

本地跑时用占位 `database_id` 即可，Wrangler 会在本机生成 SQLite，**不要**改成 Cloudflare 线上库 ID，也不要登录 Cloudflare。

若 `name` 字段是 `sites-project` 可改成 `order-race-h5`，不影响功能。

## 6. 配置口令（必做）

在 `$APP` **根目录** 和 `$APP/dist/server/` 各放一份（Wrangler 读配置文件同目录下的密钥）：

```bash

```

`$APP/.dev.vars` 与 `$APP/dist/server/.dev.vars` 内容相同：

```ini
CONTROL_PASSWORD=2026
SESSION_SECRET=这里填上一步生成的至少24位随机串
```

- `CONTROL_PASSWORD`：录入页 `/control` 口令。当前活动约定为 `2026`，上线前与业务确认。
- `SESSION_SECRET`：登录 Cookie 签名，**不要**用示例值，也不要提交进 Git。
- `.dev.vars` 已在 `.gitignore` 中，不要入库。

每次重新 `npm run build` 后，再执行一次：

```bash
cp $APP/.dev.vars $APP/dist/server/.dev.vars
```

## 9. Nginx HTTPS 反代

证书按公司现有流程配置（Let’s Encrypt 或公司证书）。关键是把 **真实域名** 和 **https** 传给后端。

配置文件：`/etc/nginx/conf.d/order-race-h5.conf`。证书放在 `/etc/nginx/certs/`，文件名若不同只改 `ssl_certificate` 两行。

```nginx
server {
    listen 80;
    server_name lzmorder.linggandaquan.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name lzmorder.linggandaquan.com;

    ssl_certificate     /etc/nginx/certs/lzmorder.linggandaquan.com.pem;
    ssl_certificate_key /etc/nginx/certs/lzmorder.linggandaquan.com.key;

    client_max_body_size 20m;

    location / {
        proxy_pass http://127.0.0.1:8787;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_read_timeout 60s;
        proxy_buffering off;
    }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

不要把 `Host` 改成 `127.0.0.1`，否则 Cookie / 跳转可能异常。

## 12. 运维注意

1. **备案**：域名指到大陆机房提供网站服务，按公司合规流程完成 ICP 备案后再对外。
2. **不要**在服务器上执行 `wrangler login` / `wrangler deploy`，避免误发到 Cloudflare。
3. 启动必须带 `--local`（本仓库锁定的 Wrangler 4.92 没有 `--experimental-autoconfig`），避免连 Cloudflare。不要加 `-r` / `--remote`。
4. 构建失败、进程被杀：优先查内存（`dmesg | grep -i kill`）。
5. 登录后立刻失效：检查 Nginx 是否传了 `X-Forwarded-Proto https`，以及站点是否全程 HTTPS。
6. 预览动效要点「进入全屏并开启声音」后才会播，这是产品设计，不是故障。
7. 日志：`journalctl -u order-race-h5 -n 200 --no-pager`。
