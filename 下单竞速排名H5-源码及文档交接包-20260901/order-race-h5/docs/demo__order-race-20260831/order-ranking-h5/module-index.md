## 1. 使用规则

- YAML front matter 中的 `current_module_baseline` 是本迭代该模块唯一当前指针。
- `baselines/<module-baseline-id>/` 是不可变完整快照，不得原地改写。
- `changes/<task-id>/` 保存一次变更的完整交付过程；已关闭 task 不得回写。
- 只有目标迭代已包含候选且约定验收通过后，才能创建新 baseline 并切换当前指针。
- 收口时先发布 baseline 和 task 回填，最后原子切换本索引；本索引是唯一提交点。
