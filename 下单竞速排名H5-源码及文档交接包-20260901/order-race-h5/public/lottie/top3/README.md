# 全国前三赛车动效

- `top3.json`：1920 × 1080，60 fps，5 秒，Lottie light SVG 播放器兼容。
- `track.png`：根据用户效果图制作的无文字赛道。
- `car.png`：独立透明车身，三个实例分别拥有位置、缩放、车身震动、灯光及倒影轨道。
- 省名和祝贺文字由 React 渲染；动画 JSON 中的 TOP 3 概念始终表示“进入前三”，并不表示该省一定排名第三。
- 场景包含反向旋转光环、形变棋盘旗、独立桂冠叶片、皇冠漂浮、赛车冲刺、地面光流和金色碎片。
- JSON 的三张车身实例共用一个图片资源，不是把完整海报整体缩放。
- 所有动画由一个时间位置驱动；预览时间轴可以前后拖动，省名可以切换。尊重系统“减少动态效果”设置。

重新生成：`node scripts/create-top3-lottie.mjs`。

预览地址：`/preview/top3`。正式接入位置：`CelebrationLayer` 的 `top3` 事件分支。
