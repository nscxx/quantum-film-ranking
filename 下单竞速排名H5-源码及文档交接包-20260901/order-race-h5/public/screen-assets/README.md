# 大屏素材清单（请按文件名投放）

把做好的 PNG 直接放到本目录，刷新大屏即替换对应槽位。不要改文件名。

统一要求：

- 格式：`PNG-24`，透明底
- 颜色空间：sRGB
- 光晕画进图里（不要抠得太干净，暗底发光物体连光一起出）
- 不要白底、不要 JPEG
- 不要在图上写中文标题或数字（数字由页面实时渲染）

参考效果图：仓库外客户那张「量子膜订单竞争榜」原图（1024×576）。本目录若放 `_reference.png`，开发时访问 `/?overlay=1` 可半透明叠图对位。

## 可选品牌源文件

放到 `public/fonts/`：

- 中文：客户指定的黑体 / 圣戈班品牌中文字体（`.otf` / `.woff2`）
- 数字：等宽工业风（DIN、Tabular）

没有字体文件时页面继续用系统黑体，数字用 `tabular-nums`。

## 不要另做的

- 中国地图省份形状：已用本地 `public/data/china-provinces.json`，颜色跟积分档走。做一张死图会盖住热力。
- 排行榜条、环、切角框、标题字：页面生成。
- 南海诸岛小图：已用同一份地图数据。

## 投放后怎么验收

1. 文件名完全一致，刷新 `http://localhost:3000/`
2. 缺文件时该槽位自动退回 CSS 占位，不会破版
3. `/?overlay=1` 对照效果图看位置
